# hybrid-cnn-transformer-skin-lesion-classification
Research on metadata-aware Hybrid CNN–Transformer architectures for 8-class skin lesion classification using the ISIC-2019 dataset. Proposes a lightweight MobileNetV2–ViT model and a dual-backbone DEKAN architecture integrating DenseNet-121, EfficientNet-B0, attention-based feature fusion, clinical metadata, and KAN classification.
